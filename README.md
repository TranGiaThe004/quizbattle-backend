# QuizBattle Backend

Backend service for QuizBattle realtime quiz battle platform.

## Tech Stack

- Python 3.13
- Miniconda
- FastAPI
- WebSocket
- PostgreSQL
- SQLAlchemy 2.0
- Alembic
- Redis
- JWT Authentication
- Docker Compose
