# QuizBattle - Modules

## M00 - Project Setup & Documentation

Quản lý setup ban đầu: Jira, GitHub, docs, README, Git workflow, Docker và project skeleton.

## M01 - Authentication

Quản lý đăng ký, đăng nhập, đăng xuất, refresh token và protected route.

## M02 - Quiz Management

Quản lý tạo, xem, sửa, xóa quiz. Mỗi quiz thuộc về một owner.

## M03 - Question Management

Quản lý câu hỏi Multiple Choice và True/False. Mỗi câu hỏi có time limit.

## M04 - Game Room & Lobby

Host tạo phòng, player join bằng mã phòng, lobby hiển thị danh sách player realtime.

## M05 - Realtime Gameplay

Host start game, server gửi câu hỏi, timer, nhận đáp án, chấm điểm và tự chuyển câu.

## M06 - Leaderboard

Tính điểm và cập nhật bảng xếp hạng live sau mỗi câu.

## M07 - Game Result

Lưu và hiển thị bảng xếp hạng cuối cùng.

## M08 - Chat Realtime

Bonus: chat realtime trong phòng.

## M09 - Public Quiz Library

Bonus: chia sẻ quiz public và xem danh sách quiz public.

## M10 - Personal Statistics

Bonus: thống kê số game đã chơi, điểm trung bình và lịch sử chơi.

## M11 - UI & Mobile Polish

Tối ưu responsive mobile, sound effect, confetti và trải nghiệm người dùng.

## M12 - DevOps & Docker

Quản lý Docker Compose, PostgreSQL, Redis, .env.example, README setup.
